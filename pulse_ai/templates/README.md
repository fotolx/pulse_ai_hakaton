# Инженерные коллекторы Москвы

Диспетчерский интерфейс мониторинга инженерных коллекторов: карта сети, карточки узлов, оснащение и датчики, прогноз инцидентов, передача смены и уведомления выездных бригад.

## Экраны

| Адрес | Экран |
| --- | --- |
| `index.html#/` | Город |
| `index.district#` | Административный округ |
| `pickets.html` | Район и карточки узлов |
| `equipment.html` | Оснащение и датчики |

Прогноз инцидентов, передача смены и уведомления открываются из верхней панели.

## Структура

- `js/pages/` — экраны сервиса.
- `js/components/` — компоненты интерфейса.
- `js/services/` — работа с данными, хранение и API.
- `js/data/` — исходные данные и конфигурация.
- `css/`, `img/`, `vendor/` — стили, изображения и библиотеки.
- `scripts/` — HTTP-сервер и API обмена с бригадами.
- `tests/` — автоматические проверки.
- `docs/` — описание API и развёртывания.
